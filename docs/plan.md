# plan.json 字段说明

`plan.json` 是一个助手的全部配置。生成器写它，浮窗只读它。手改之后保存，浮窗几秒内自动重新载入。

读取是宽容的：缺的字段补默认值，写错的值丢掉，不认识的键忽略。改坏到不是合法 JSON 时，浮窗沿用上一版能用的配置，并在标题栏用红字提示。

完整的例子见 [examples/plan-student.json](../examples/plan-student.json)。

## 时间的约定

- 时间一律写 `"HH:MM"`，24 小时制。
- `day_start` 是换日时间，默认 `"05:00"`。0 点到换日时间之间仍算前一天：凌晨 1 点勾掉的时间块记在前一天，写在模板里的 `"00:30"` 排在当天最后。
- 睡觉时间早于或等于起床时间，按第二天凌晨算。

## 顶层字段

| 键 | 类型 | 说明 |
| --- | --- | --- |
| `assistant` | 对象 | `name` 助手名（最长 12 字）、`owner` 你的称呼、`tone` 语气（`direct` / `warm` / `strict`）、`accent` 主色（`#rrggbb`）、`lines` 没有提醒时助手条显示的话（`morning` / `day` / `night`，各最长 40 字） |
| `modules` | 对象 | 模块开关，见下 |
| `day_start` | 时间 | 换日时间，`00:00` 到 `08:00` |
| `wake` / `sleep` | 对象 | `{"default": "07:30", "sat": "09:00"}`。`default` 必有，按星期（`mon` 到 `sun`）覆盖。`sleep` 的星期指当天晚上 |
| `wrap_before_sleep` | 分钟 | 睡觉线前多久提醒收尾，0 到 180，默认 45 |
| `day_types` | 对象 | 日子的类型：`{"class": "上课日", "rest": "休息日"}`。键用小写字母、数字、下划线 |
| `week` | 对象 | 每个星期属于哪一类：`{"mon": "class", …}` |
| `templates` | 对象 | 每一类日子的时间块列表，见下 |
| `habits` | 列表 | `{"name": "阅读 20 分", "by": "22:30"}`。`by` 是最晚完成时间，可省。最多 12 个 |
| `water` | 对象 | `cup_ml` 一杯多少毫升（默认 250）、`goal_ml` 每天目标（默认 2000） |
| `nutrition` | 对象 | `kcal`、`protein` 每天目标，0 表示不设；`quick_food` 快捷食物 `[{"name", "kcal", "p"}]` |
| `training` | 对象 | 见下 |
| `countdowns` | 列表 | `{"name": "期末考试周", "date": "2027-01-11"}` |
| `maintenance` | 列表 | 周期事务：`{"name": "换滤芯", "every": 90}`，`every` 是天数 |
| `people` | 列表 | 联络：`{"name": "爸妈", "every": 7, "topic": "视频通话"}` |
| `goals` | 列表 | `{"name": "…", "date": "2026-12-12", "metric": "…"}`，后两项可省。有日期的会进倒计时 |
| `owner` | 对象 | `priorities` 各领域的优先顺序、`floors` 底线。问答时作为约束交给模型 |
| `rules` | 列表 | 个性化的提醒规则，见下。最多 16 条 |
| `review_template` | 文本 | 每晚复盘的模板 |
| `focus_min` | 分钟 | 一次专注的默认时长 |
| `qa` | 对象 | `model` 问答用的模型（`sonnet` / `opus` / `haiku` / `fable`）、`claude_path` Claude Code 的路径（一般不用填） |
| `ui` | 对象 | `alpha` 不透明度（0.5 到 1.0）、`width` 宽度（300 到 520） |

## 时间块

`templates` 的每一项是一个列表，元素是时间块：

```json
{"t": "19:00", "m": 90, "name": "作业与复习", "type": "study", "dnd": true, "note": "先写截止最近的", "days": ["mon", "wed"]}
```

| 键 | 说明 |
| --- | --- |
| `t` | 开始时间，必填 |
| `name` | 名称，必填，最长 24 字 |
| `m` | 时长（分钟）。不写表示持续到下一块开始；最后一块不写表示到睡觉线 |
| `type` | 类型，决定颜色和是否要勾选，见下表 |
| `dnd` | `true` 表示勿扰：这段时间只放行优先级 80 以上的提醒 |
| `note` | 备注，最长 60 字。时间块进行时显示在它下面 |
| `days` | 只在这些星期出现。不写表示这类日子每天都有 |
| `fixed` | `true` 表示是你的固定安排。生成器用它标记不许 AI 改动的块，浮窗里显示「固定」 |

时间块重叠时，前一块截到后一块开始。每类日子最多 30 个。

类型：

| `type` | 名称 | 要勾选 |
| --- | --- | --- |
| `work` | 工作 | 是 |
| `study` | 学习 | 是 |
| `class` | 上课 | 是 |
| `meeting` | 会议 | 是 |
| `create` | 创作 | 是 |
| `train` | 训练 | 是 |
| `meal` | 用餐 | 是 |
| `chore` | 杂务 | 是 |
| `care` | 照护 | 是 |
| `commute` | 通勤 | 否 |
| `social` | 社交 | 否 |
| `rest` | 休息 | 否 |
| `free` | 自由 | 否 |
| `flex` | 机动 | 否 |

不要勾选的类型不计入完成率。

## 训练

```json
{"mode": "queue", "queue": ["push", "pull", "legs"],
 "programs": {"push": {"name": "推", "ex": [["卧推", 4, "6–8"], ["肩推", 3, "8–10"]]}}}
```

- `mode` 为 `queue`：按队列轮转，练完一节才轮到下一节，没练的留在队首。当天的日程里有 `train` 类型的时间块才算「今天该练」。
- `mode` 为 `split`：按星期固定，另写 `"split": {"mon": "push", "tue": null, …}`。
- `ex` 的每项是 `[动作, 组数, 次数]`。

## 提醒规则

内置的提醒不用配置：时间块结束未勾、待办临期或过期、睡前收尾、过了睡觉线、习惯临期、喝水落后、周期事务和联络到期、倒计时临近、复盘未写。

`rules` 是在此之外的个性化规则：

```json
{"id": "phone_down", "when": {"after": "23:00", "weekdays": ["sun", "mon", "tue", "wed", "thu"]},
 "say": "明天有课，现在把手机放远，准备睡。", "why": "你说晚上刷手机拖到一点多，第二天早课起不来。",
 "priority": 75, "tab": "schedule", "cooldown_min": 180}
```

| 键 | 说明 |
| --- | --- |
| `id` | 英文短名，反馈统计按它记 |
| `when` | 触发条件，全部成立才触发，至少一个 |
| `say` | 助手条上显示的话，最长 48 字 |
| `why` | 依据，点助手条的文字时显示 |
| `priority` | 1 到 100。多条同时成立时显示最高的；80 以上在勿扰时段也会出现 |
| `tab` | 点「采纳」后跳到哪个页：`schedule` / `todo` / `log` / `review` |
| `cooldown_min` | 采纳之后多久内不再提，默认 180 分钟。点「不用」则当天不再提 |

`when` 可用的条件：

| 条件 | 值 | 含义 |
| --- | --- | --- |
| `after` / `before` | 时间 | 现在不早于 / 早于这个时间。凌晨算前一天的深夜，所以 `after: "23:00"` 在凌晨 1 点仍成立 |
| `weekdays` | 星期列表 | 今天是其中之一 |
| `day_types` | 类型列表 | 今天属于其中一类 |
| `habit_undone` | 习惯名 | 这个习惯今天还没勾。名字必须在 `habits` 里 |
| `block_type_now` | 类型列表 | 现在所在的时间块是其中一种 |
| `no_block_now` | `true` | 现在不在任何时间块里 |
| `done_pct_below` | 1–100 | 今天到点该完成的时间块，完成率低于这个数 |
| `water_pct_below` | 1–100 | 喝水不到目标的百分之几 |
| `protein_pct_below` | 1–100 | 蛋白不到目标的百分之几 |
| `kcal_pct_above` | 1–300 | 热量超过目标的百分之几 |
| `todo_due_within_h` | 小时 | 有待办在这么多小时内到期（含已过期） |
| `todo_open_at_least` | 条数 | 未完成的待办不少于这么多 |
| `min_to_sleep_below` | 分钟 | 距睡觉线不到这么多分钟（还没过线） |
| `past_sleep_min` | 分钟 | 过了睡觉线这么多分钟以上 |
| `training_undone` | `true` | 今天该练而没练 |
| `review_undone` | `true` | 今天的复盘没写 |

条件依赖的模块没开，这条规则永远不会触发。规则和内置提醒说的是同一件事时（比如都在提同一个没做的习惯），只显示规则的说法，分数取两者中高的。
